AARU UNIVERSE — MUSIC

Replace:
  public/music/our-song.mp3

with your own audio file.

Keep the filename:
  our-song.mp3

No code changes required.
Supported: mp3, m4a, ogg, wav (mp3 recommended).

The song starts only after the user clicks:
  "Enter our universe ♡"

It will loop and continue smoothly across all scenes.
If the file is missing, the website still works — music control will show graceful failure.

Tip: keep file under ~6 MB, 128-192 kbps mp3 for fast mobile loading.
